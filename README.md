# DevOpsWiki Backend

REST API for the DevOpsWiki application, built with FastAPI and PostgreSQL.

## Tech Stack

- **FastAPI** — API framework
- **SQLAlchemy** — ORM
- **PostgreSQL** — Database
- **Pydantic** — Data validation
- **Uvicorn** — ASGI server

## Prerequisites

- Python 3.10+
- PostgreSQL database
